# CV en ligne – Fadila Bensaid

## Présentation

Ce projet consiste à réaliser un CV en ligne en HTML et CSS.

Le site présente mon profil professionnel, mes compétences, mes expériences et mes formations dans une mise en page structurée et accessible.

## Technologies utilisées

- HTML5
- CSS3
- Flexbox
- Git
- GitHub

## Fonctionnalités

- Structure HTML sémantique
- Mise en page avec Flexbox
- Photo de profil avec effet au survol
- Liens de contact cliquables
- Liens vers LinkedIn et GitHub
- Effets visuels au survol
- Favicon personnalisé

## Organisation du projet

- `index.html` : structure du CV
- `css/` : feuille de style CSS
- `images/` : images et icônes utilisées dans le CV
- `favicon.ico` : icône du site

## Gestion du projet avec GitHub

Le développement du projet a été réalisé avec Git et GitHub en utilisant :

- une branche principale `main`
- une branche de développement `DEV`
- des branches dédiées aux modifications
- des commits pour suivre les évolutions
- des Pull Requests pour intégrer les modifications dans la branche principale
